# Modeling-Attack Resistance versus Reliability Trade-off of Arbiter, XOR, and Interpose PUFs

Reproducibility archive for the manuscript

> **Modeling-Attack Resistance versus Reliability Trade-off of Arbiter, XOR, and Interpose PUFs: A Reproducible Simulation Study**
> Fatih Gül, Department of Electrical and Electronics Engineering and the Artificial Intelligence and
> Internet of Things Research Laboratory, Recep Tayyip Erdoğan University, Rize, Türkiye
> (ORCID [0000-0001-5072-2122](https://orcid.org/0000-0001-5072-2122)) — *under peer review, 2026*

All challenge–response pairs (CRPs) analysed in the paper are generated by the field-accepted
**additive linear delay model** of the Arbiter PUF. **No silicon measurements are used or claimed.**

## Contents

| Path | Description |
|---|---|
| `code/puf_models.py` | Additive linear delay simulator: APUF, k-XOR APUF, (x,y)-Interpose PUF, Gaussian stage-noise reliability model |
| `code/run_experiments.py` | Main sweep: LR and MLP modeling attacks over k = 1…6, n ∈ {64,128}, training budgets 10³…2×10⁵; BER measurement |
| `code/expand_ipuf.py` | Interpose-PUF attacks — (1,1), (1,2), (2,2) — and the (σ, k) BER surface |
| `code/make_figures.py` | Regenerates every figure and summary table from the result CSVs |
| `results/*.csv` | All numbers reported in the paper |
| `figures/*.{pdf,png}` | All figures in the paper |

## Reproducing every number

```bash
python3 -m pip install numpy scipy scikit-learn matplotlib
cd code
python3 run_experiments.py     # attack accuracy + reliability sweeps  -> ../results/*.csv
python3 expand_ipuf.py         # Interpose-PUF attacks + (sigma,k) BER surface
python3 make_figures.py        # all figures and summary tables
```

All experiments use fixed seeds, so the CSVs and figures are reproduced bit-for-bit.
